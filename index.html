How to connect

Browser synth (no setup)

The default mode. Sound plays through this page. Use headphones for best results.

MIDI → DAW (Ableton, Logic, etc.)

Glissando sends MPE messages over Web MIDI to any DAW or software synth on the same device.

On Mac: create an IAC bus in Audio MIDI Setup (built into macOS). In Ableton's MIDI preferences, enable Track + MPE for the IAC bus. Glissando will auto-select it.

On Windows: install loopMIDI (one-time, free). Create a port named "Glissando". In Ableton's MIDI prefs, enable Track + MPE for that port.

On Android tablet → laptop via USB: plug the tablet into your laptop. On the tablet, change USB mode to "MIDI". The tablet appears as a native MIDI device on the laptop. Open Glissando in Chrome on the tablet, switch output to MIDI, pick "Glissando" or your tablet's name on the laptop side.

Ableton track setup

Create a MIDI track, set input to your MIDI device, arm the track, drop an MPE-aware instrument (Wavetable, Vital, Surge XT, ROLI Equator). Enable MPE for the input under Preferences → MIDI.

Controls

Snap modes: free = continuous pitch, pull = gravity wells around tonics and fifths, lock = locks to scale notes.

Slide ↑ / Slide ↓: what your Y-axis (vertical finger position) controls. Affects the browser synth only — MIDI output always sends CC74 (the MPE standard) for Ableton's instrument to map.

Panic: instantly silences all sound. Use if any notes get stuck.
